# Design System — EduLLM SAT Math

Visual identity extracted from Jinja2 HTML templates in `src/edullm_sat/templates/`.
The UI is a GitHub-inspired monochrome design: dark charcoal header, light grey page
background, white content cards, and a blue link accent. Monospace type is used throughout
the shell chrome; a system sans-serif stack is used for prose/article content.

name: EduLLM SAT Math
colors:

  background: "#f6f8fa"

  error-background: "#ffebe9"

  header-button-border: "#444c56"
